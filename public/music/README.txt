# Instruksi untuk Musik Religi

Untuk menambahkan musik religi ke website undangan pernikahan, silakan:

1. Ganti file ini dengan file musik religi MP3 atau OGG
2. Pastikan nama file adalah:
   - `religious-music.mp3` (format utama)
   - `religious-music.ogg` (format alternatif)

Rekomendasi musik religi yang cocok untuk undangan pernikahan:
- Nasheed islami yang lembut
- Tilawatil Quran yang melodius
- Musik instrumental religi

Pastikan file musik:
- Berkualitas baik
- Tidak terlalu keras
- Panjangnya sekitar 3-5 menit (akan di-loop)
- Format yang didukung browser (MP3/OGG)

Contoh musik yang bisa digunakan:
- "Ya Rasulallah" - Maher Zain
- Tilawatil Quran - Mishary Rashid Alafasy
- Nasheed islami instrumental

Catatan: Beberapa browser memblokir auto-play musik. User perlu mengklik tombol play secara manual.
